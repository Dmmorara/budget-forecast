# version recorded in models/ensemble-v1.manifest.json.
#
# That move does not mean a slow build. PyPI has a scikit-learn 1.5.2 wheel
# for CPython 3.11 on manylinux x86-64, which is what the service's
# python:3.11-slim image runs, so pip installs it prebuilt. The six-minute
# compile seen on Render was most likely the static site's builder, which
# installed requirements.txt on its default Python 3.14, for which 1.5.2 has
# no wheel. That is an inference: no Render build log confirms it.
