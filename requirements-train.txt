# Training only: scripts/build_panel.py and scripts/fit_model.py.
#
# scikit-learn and joblib are in requirements.txt now: the service unpickles
# models/extratrees-v2.joblib at runtime, so they are runtime dependencies, at
# the versions its manifest records. Fitting needs nothing beyond them today.
# Anything only fitting needs goes here, not in requirements.txt, so it stays
# out of the service image.
#
# Moving scikit-learn into requirements.txt should not mean a slow build. PyPI
# has a scikit-learn 1.5.2 wheel for CPython 3.11 on manylinux x86-64, which is
# what the service's python:3.11-slim image runs, so pip installs it prebuilt.
# The six-minute compile seen on Render was most likely the static site's
# builder, which installed requirements.txt on its default Python 3.14, for
# which 1.5.2 has no wheel. That is an inference: no Render build log
# confirms it.
-r requirements.txt
